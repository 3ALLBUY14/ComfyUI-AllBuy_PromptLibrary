# ComfyUI-AllBuy_PromptLibrary

专为**大段视频提示词**设计的提示词库插件：把每一段提示词保存为带名字、可预览的"卡片"，勾选即生效，多选时多组按顺序自动合并成一条提示词输出。

## 功能特性

- **勾选即生效**：卡片前的复选框勾选后，该段提示词进入最终输出；取消即移除。
- **多选叠加**：同时勾选多组，按"勾选顺序"拼接；已选卡片自动置顶，可**拖拽排序**调整合并顺序。
- **命名 + 预览**：节点上只显示名称和颜色标记，保持紧凑；点 👁 预览整段提示词，点"预览合并"查看最终拼接结果（按卡片分块着色）。
- **正/负向双输出**：每个卡片可单独填写负向提示词，节点分别输出 `positive` 和 `negative` 两个 STRING，直接接你自己的文本编码节点（兼容 Wan / HunyuanVideo / CogVideo / SVD 等）。
- **长文本友好**：大段提示词在弹窗里编辑，节点不被撑爆；支持权重、前缀/后缀。
- **搜索与分类**：按名称、正文、标签搜索，按分类筛选。
- **三种库来源**：
  - 📦 **内置库**（插件自带，只读示例）
  - 🗂 **用户库**（`ComfyUI/user/allbuy_promptlibrary/`，可增删改，全局共享）
  - 📎 **内嵌库**（导入 JSON 文件，数据随工作流保存，方便打包分发）
  - 📄 **外部文件**（引用任意路径的 JSON，只读）
- **分隔符可选**：逗号+空格（默认）、换行、句号、分号、自定义。
- **通配符 `{a|b|c}`**：卡片正文 / 前缀后缀 / 前置后置文本都支持，每次执行随机选一，支持嵌套（如 `{small {red|blue}|big}`）。
- **通配符固定种子（v3.51）**：footer 🎲 按钮可把通配符随机固定成可复现的种子，随时可取消恢复每次随机。
- **执行中锁定（v3.51）**：队列执行本节点期间面板只读并显示状态条，可点「解锁编辑」强制恢复。
- **旁路视觉同步（v3.51）**：节点被静音/旁路（Ctrl+M）时 DOM 面板同步变暗并标注「已旁路」。
- **调色隔离（v3.51）**：面板自带不透明底色，右键调色只影响节点框架，不再染进内部 UI。
- **随机抽卡节点**：`Random Draw（随机抽卡）` 从指定库随机抽 N 张合并输出，seed 可复现，适合批量出图找组合灵感。
- **素材加载节点（v3.54）**：`素材加载（图/音/视频）`——拖入/文件选择器/文件夹/Ctrl+V（悬停面板时）入料，素材复制到 `input/allbuy_media/` 持久化；图片/音频/视频三 Tab 分类浏览，JS 显式分列瀑布流；图片多选（点选即生效，序号徽标 = batch 顺序，可拖拽排序）+ 音/视频单选；内置缩放设置（最长边/最短边/宽/高 + 8/16 对齐）；输出 图片 / 视频帧 / 帧率 / 音频 / 素材JSON 五个口。**视频**：⚙ 设选区（起点/终点秒）+ 目标帧率（0=原速）+ 总帧上限，保存前实时显示输出帧数，cv2 逐帧解码（时间累积重采样，4096 帧硬上限防失控）。**音频**：⚙ 波形选区裁剪（PyAV 解码出峰值画波形，可试听选区），按起点/时长裁剪输出标准 AUDIO。
- **前后端版本握手**：节点 footer 显示版本号；前端自动检测后端是否重启到新版，不一致时控制台警告 + footer 标注 ⚠。
- **持久化**：勾选状态、分隔符、前置/后置文本随工作流保存；库文件写入时自动备份 `.backup`。

## 安装

把本文件夹放到 ComfyUI 的 `custom_nodes/` 目录下，重启 ComfyUI：

```
ComfyUI/custom_nodes/ComfyUI-VideoPromptLibrary/
```

或通过 ComfyUI-Manager → "Install via Git URL" 安装。

## 使用

1. 在节点列表中找到 **VideoPromptLibrary（视频提示词库）**（分类 `VideoPromptLibrary`），添加到工作流。
2. 节点上点 **＋ 新建提示词组**，填写名称、分类，把大段视频提示词贴进"正向提示词"框，保存。
3. 勾选卡片：勾哪组生效哪组；勾多组自动合并。
4. 已选卡片可拖拽 ⋮⋮ 调整顺序（决定拼接先后）。
5. 点 **👁 预览合并** 查看最终提示词，确认无误后把节点的 `positive` / `negative` 输出接到文本编码节点。
6. 点 **📥** 可导入外部 JSON 库文件（内嵌到工作流，换电脑也不丢）。

### 节点输出

| 节点 | 输出 | 说明 |
|---|---|---|
| Video Prompt Library | positive / negative | 勾选卡片按顺序合并 |
| Random Draw（随机抽卡） | positive / negative | 按 seed 随机抽 N 张合并 |

### 通配符语法

卡片正文中写 `{a|b|c}`，每次执行随机选一项；选项自动去首尾空格；支持嵌套。主节点（Video Prompt Library）无 seed 输入，每次出队都会重新抽取；需要可复现结果时用**随机抽卡**节点（seed 固定 = 结果固定）。

### 高级设置（点 ⚙ 展开）

- **前置文本 / 后置文本**：拼接到合并结果的最前/最后。
- **导出 JSON**：把当前库下载为文件。
- **另存为用户库**：把内置/内嵌/外部库复制一份到用户库进行编辑。

## 库文件格式

用户库位于 `ComfyUI/user/allbuy_promptlibrary/*.json`，格式：

```json
{
  "version": 1,
  "name": "我的库",
  "groups": [
    {
      "id": "g-xxxx",
      "name": "电影感慢推镜头",
      "category": "镜头运动",
      "positive": "Cinematic slow dolly-in, 35mm anamorphic lens ...",
      "negative": "shaky cam, fast cuts ...",
      "note": "备注",
      "color": "#4A90D9",
      "weight": 1.0,
      "prefix": "",
      "suffix": "",
      "tags": ["电影感", "推镜"],
      "cover": ""
    }
  ]
}
```

- `weight` 不为 1.0 时，整段会被包裹为 `(text:1.1)`。
- `prefix` / `suffix` 会拼在该段文本前后。
- 可手动编辑 JSON，重启或切换库后生效；保存时会自动生成 `.backup`。

## 合并规则

1. 取所有勾选卡片，按列表中的已选顺序排列；
2. 每段拼成 `prefix + positive + suffix`，权重 ≠ 1 时包裹 `(text:w)`；
3. 用分隔符连接各段；
4. 前置文本 + 合并结果 + 后置文本；
5. 负向提示词走同样流程（不附加前置/后置）。

## 已知限制 / 规划

- 封面缩略图、槽位模式（slot）、A1111 styles.csv 导入等进阶功能在规划中（下一批）。
- 随机抽卡节点的库下拉列表在节点创建时生成，新建库后需刷新节点（R 键）才能出现在列表中；也可直接在框里输入 `user:库名`。
- 外部文件（custom path）模式下浏览器无法直接获得文件真实路径，需手动输入绝对路径；若希望工作流自包含，推荐用"导入文件（内嵌）"。

## 更新日志

### v3.55（视频口）
- 素材加载节点输出调整（应用户要求移除「视频」「素材JSON」两口）：现为 **图片 / 遮罩 / 视频帧 / 视频音频 / 帧率 / 帧计数 / 视频信息 / 音频** 八口——视频文件化走「⬇ 导出 MP4」，结构化信息走「视频信息」口（VHS_VIDEOINFO，含选区帧数/帧率/时长/宽高双套），视频原声走「视频音频」口（按选区窗口裁剪）。帧序列/原声/信息仅在选择视频且参数有效时计算，纯图片工作流零额外开销。

### v3.55（导出接口）
- 图片与视频帧导出：
  - `GET /media/export/image?name&x0&y0&x1&y1&scale_*` → 编辑后图片 PNG（裁剪框+缩放实时生效）；图片 ⚙ 弹窗「⬇ 导出 PNG」。
  - `GET /media/export/frame?name&t&scale_*` → 视频指定时间点抽帧 PNG；视频 ⚙ 弹窗「⬇ 首帧 / ⬇ 尾帧」（按当前选区出入点抽帧，尾帧取终点前 50ms）。
- 新增视频/音频文件导出（弹窗内一键下载裁剪片段）：
  - `GET /media/export/video?name&start&end&fps&max_frames&scale_*` → MP4 文件（ffmpeg libx264 编码，缺失时退化 cv2 mp4v；解码/编码在线程池不阻塞服务器）。
  - `GET /media/export/audio?name&start&duration` → 16-bit 立体声 WAV（纯标准库编码）。
  - 视频 ⚙ 弹窗「⬇ 导出 MP4」、音频 ⚙ 弹窗「⬇ 导出 WAV」，当前选区/帧率/帧数/缩放实时生效；下载文件名带原素材名 + `_clip`。

### v3.54（P2/P3 补全）
- 修复：素材文件名含 `#`、emoji、全角标点时 `/media/wave`、`/media/thumb`、`/media/vthumb` 全部 404（波形/缩略图缺失的根因）——路径校验改为「basename 单段 + 规范化根目录边界校验」，不再用字符白名单限制文件名内容（防穿越能力不变，由边界校验兜底）。

- 素材加载节点接入视频与音频全功能：
  - 视频帧输出口：⚙ 弹窗设选区（起点/终点秒）+ 目标帧率（空=原速）+ 总帧上限，实时显示「选区 × fps = N 帧（截断）」；cv2 逐帧解码 + 时间累积重采样（VHS 同公式），4096 帧硬上限防失控；帧率数值单独输出口。

  - 修复：素材文件名白名单支持 Unicode（中文文件名缩略图 404）；视频选区终点在重采样模式下同样生效；音频 PCM 缓存收紧到 8 条防内存膨胀。
